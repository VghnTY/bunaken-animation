# Tokoh

## Nara — protagonis

| | |
|---|---|
| Usia | 19 |
| Peran | Dive guide magang, anak nelayan |
| Ingin | Sekolah kelautan di Manado |
| Butuh | Mengakui bahwa kampungnya butuh dia sekarang |
| Ketakutan | Menjadi orang yang meninggalkan laut saat laut butuh dia |
| Ciri visual | Rash guard teal pudar, jam selam di tangan kiri, rambut pendek hitam |

**Busur:** dari remaja yang hanya menikmati laut → menjadi orang yang bertanggung
jawab atas laut. Bukan lewat pidato, tapi lewat keputusan sulit.

**Kalimat kunci:** *"Kalau bukan kita yang jaga, siapa lagi?"* — dipakai **sekali**
saja, di Scene 3. Jangan diulang.

## Pak Daniel — ayah Nara

| | |
|---|---|
| Usia | 52 |
| Peran | Nelayan tradisional |
| Ingin | Anaknya sekolah, keluarganya makan |
| Butuh | Mengakui bahwa ia mengambil jalan pintas karena takut |
| Konflik | Ikut Haris di Scene 2 |

**Busur:** dari tunduk pada tekanan → berani mengakui kesalahan di Scene 3 →
mengajarkan cara benar di Scene 4. Pak Daniel adalah **cermin** dari penonton
dewasa: orang baik yang membuat pilihan buruk karena terdesak.

## Pak Haris — antagonis

| | |
|---|---|
| Usia | 45 |
| Peran | Nelayan pendatang, pemakai bom & jaring dasar |
| Ingin | Melunasi utang dan hidup tenang |
| Butuh | Diberi alternatif, bukan dihukum |
| Ketakutan | Kembali miskin seperti di kampung asalnya |
| Ciri visual | Kaos abu pudar, topi lusuh, bekas luka di lengan kanan |

**Aturan penulisan:** Haris **tidak boleh** terlihat senang merusak. Setiap kali
ia mengebom, tunjukkan ia tidak nyaman. Di Scene 3, ia tidak membela diri —
ia diam. Diamnya Haris adalah pengakuan.

## Tokoh pendukung (tanpa nama)

- **Warga dermaga** — membela Haris karena ekonomi, bukan karena jahat.
- **Anak-anak kampung** — muncul di Scene 1 dan Scene 4 sebagai penanda masa depan.
- **Pengelola taman nasional** — hanya suara/figur jauh, tidak perlu model detail.

## Yang tidak boleh dilakukan

- Jangan membuat Haris tertawa jahat atau berteriak "aku akan menghancurkan karang!".
- Jangan membuat Nara sempurna; ia harus salah minimal sekali (Scene 2: ia
  memilih meninggalkan kampung sebelum akhirnya berubah pikiran).
- Jangan memberi Pak Daniel dialog panjang. Ia tokoh yang berbicara lewat tindakan.
